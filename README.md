# Как это устроено

Репо содержит только:
- `.github/workflows/build.yml` — заливается ОДИН раз
- `source.zip` — весь Swift-исходник + project.yml, перезаливается при каждом изменении

Раннер сам распаковывает `source.zip` и собирает. Никаких отдельных файлов
руками через "Add file" каждый раз кидать не надо — только сам zip.

## Разовая настройка

1. Создаёшь репо на GitHub (веб-интерфейсом, пустой).
2. Add file → загружаешь `.github/workflows/build.yml`, сохраняя путь
   `.github/workflows/build.yml` (GitHub сам предложит создать вложенные папки,
   когда вставишь этот путь в поле имени файла при "Create new file",
   либо просто перетащи всю папку `.github` через drag&drop в "Upload files" —
   GitHub сохранит структуру).
3. Add file → Upload files → кидаешь `source.zip` в корень репо → Commit.

## Каждое следующее обновление кода

Просто перезаливаешь `source.zip` (тот же путь, тот же файл, новое содержимое) —
Upload files → перетаскиваешь новый zip → Commit changes.
Пуш триггерит workflow автоматически (see `paths:` в build.yml).

## Если меняешь Swift-файлы у меня в чате

Я пересобираю `source.zip` и кидаю тебе новый — просто заменяешь его в репе,
структуру самого репо трогать не надо.
